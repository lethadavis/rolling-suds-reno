# Rolling Suds of Reno — website

Single-page static site (`index.html` + `images/`). No build step.

- **Deploys:** Netlify publishes this folder as-is (see `netlify.toml`). Every push to `main` goes live.
- **Editing:** see the notes at the top of `index.html` and `images/README.txt`.
- **Placeholders:** search `index.html` for `tbd`.
- **Settings** near the bottom of `index.html`: `FORM_ENDPOINT` (quote form), `GOOGLE_API_KEY` (live Google reviews).
