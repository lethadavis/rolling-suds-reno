GALLERY
  Photos go in gallery/. Then add a line to the GALLERY list near the bottom of
  index.html with the file name, a title, a category and alt text.

  YouTube videos need no file. Add a line with the video ID (the part after
  "shorts/" or "youtu.be/" in the link) and short: true for YouTube Shorts.

  Categories: "before-after", "on-the-job", "video". The filter buttons above the
  gallery are built automatically from whatever categories are in use.
  featured: true makes an item a large tile (use it on one item at most).
